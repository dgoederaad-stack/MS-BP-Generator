# MS BP Generator v0.4

Versiemap voor upload naar GitHub, zoals bij MS-Station-Navigator.

Belangrijkste wijziging:
- de reconstructie is niet meer één vereenvoudigde keten;
- alle zichtbare installatieblokken/stations uit het voorbeeld zijn opgenomen;
- meerdere velden, schakelaars, aardingsschakelaars, transformatoren, rails en kabelverbindingen zijn zichtbaar;
- componenten in de digitale reconstructie zijn aanklikbaar;
- origineel en reconstructie kunnen naast elkaar of afzonderlijk worden weergegeven.

Let op:
Deze v0.4 modelleert het meegeleverde voorbeeld nog handmatig. Een willekeurige foto/PDF wordt nog niet automatisch omgezet naar dit schema. Voor de echte reader is een Vision-backend nodig die een volledig elektrisch graph-model teruggeeft.
