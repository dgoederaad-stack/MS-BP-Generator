# MS BP Generator v0.3

Deze versie is verpakt zoals de versies van MS-Station-Navigator:
je kunt de volledige map `MS_BP_Generator_v0_3` in de repository uploaden.

Functionaliteit:
- foto/afbeelding selecteren;
- PDF selecteren;
- origineel single-line tonen;
- nagetekende reconstructie tonen;
- uitgangsstanden controleren;
- normaal veld standaard Gesloten / Niet geaard;
- reserveveld standaard Open / Geaard.

Let op: de daadwerkelijke AI-herkenning van willekeurige single-lines is nog niet gekoppeld.
